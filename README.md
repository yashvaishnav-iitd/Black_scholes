# Black-Scholes Option Pricer, Greeks & Implied Volatility Solver

A from-scratch Python implementation of the Black-Scholes-Merton option pricing model, including analytical Greeks and a Newton-Raphson implied volatility solver — built to understand options pricing and volatility mechanics from first principles, not just call a library.

## Overview

This project prices European call and put options and answers three core questions:

1. **What should an option cost?** (`black_scholes`) — given the stock price, strike, time to expiry, risk-free rate, and volatility.
2. **How sensitive is that price to each input?** (`calculate_greeks`) — Delta, Gamma, Vega, Theta, and Rho.
3. **What volatility is the market actually pricing in?** (`implied_volatility`) — given an observed market price, back-solve for the volatility Black-Scholes would need to reproduce it, using Newton-Raphson iteration.

## How it works

### 1. Pricing (`black_scholes`)

Implements the standard closed-form Black-Scholes formula:

```
d1 = (ln(S/K) + (r + σ²/2)·T) / (σ·√T)
d2 = d1 - σ·√T

Call = S·N(d1) - K·e^(-rT)·N(d2)
Put  = K·e^(-rT)·N(-d2) - S·N(-d1)
```

`d1` and `d2` are computed once in a shared helper (`calc_d1_d2`) and reused across the pricer, the Greeks, and the IV solver, so the formula only lives in one place.

### 2. Greeks (`calculate_greeks`)

Analytical sensitivities of the option price to each input:

- **Delta** — sensitivity to a $1 move in the stock price
- **Gamma** — sensitivity of Delta itself to a $1 move (i.e. curvature)
- **Vega** — sensitivity to a 1% change in volatility
- **Theta** — value lost per day as time passes (time decay), reported per day
- **Rho** — sensitivity to a 1% change in the risk-free rate

### 3. Implied Volatility (`implied_volatility`)

Given a market price, this solves for the volatility that Black-Scholes would need to reproduce that exact price, using Newton-Raphson:

```
σ_new = σ_old - (BS_price(σ_old) - market_price) / Vega(σ_old)
```

Includes a guard against division by a near-zero Vega (which occurs for deep in/out-of-the-money options) and a max-iteration cap to avoid infinite loops on non-convergent inputs.

## Verification

Correctness was checked with two independent tests, not just visual inspection:

- **Round-trip consistency**: pricing an option at a known volatility, then recovering that same volatility via the IV solver, across multiple maturities (`T = 0.1, 0.5, 1.0, 2.0`) — testing only at `T = 1.0` is a known trap, since it silently hides certain arithmetic bugs (e.g. `√1 = 1` masks operator-precedence errors).
- **Put-call parity**: confirming `Call − Put = S − K·e^(-rT)` holds exactly, a standard no-arbitrage identity independent of the pricing model's internal implementation.

## Visualizing the Greeks

`plot_greeks.py` sweeps the stock price across a range (holding strike, time, rate, and volatility fixed) and plots the resulting option price and Greeks:



**What to notice:**

- **Price** rises smoothly and convexly as the stock price increases past the strike.
- **Delta** traces a classic S-curve from 0 (deep out-of-the-money) to 1 (deep in-the-money), crossing ~0.5 near the strike.
- **Gamma** and **Vega** both peak near the strike and decay on either side — option value is most sensitive to volatility and to further price moves when the outcome is still genuinely uncertain (i.e. near the strike), and least sensitive when the outcome is already nearly certain.
- The Gamma/Vega peak sits slightly below the strike rather than exactly on it — a small, expected effect of the model's drift term (the peak occurs near the forward price, `K·e^(-(r + σ²/2)·T)`, not the strike itself).

## Setup

**Requirements:** Python 3.9+

**1. Clone the repo**

```bash
git clone https://github.com/yashvaishnav-iitd/Black_scholes.git
cd Black_scholes
```

**2. Check Python is installed**

```bash
python --version
```

You should see something like `Python 3.x.x`. If this fails, install Python from [python.org/downloads](https://www.python.org/downloads/) — on Windows, make sure to check **"Add Python to PATH"** during installation.

**3. Install dependencies**

```bash
python -m pip install -r requirements.txt
```

If that says pip itself is missing, run this once first, then retry the line above:

```bash
python -m ensurepip --upgrade
```

> **Note:** Always use `python -m pip install ...` rather than plain `pip install ...`. On Windows especially, `pip` on its own often fails with `'pip' is not recognized`, even when Python is installed correctly — this happens when pip isn't separately registered on PATH. `python -m pip` runs pip as a module through Python directly, so it works regardless of PATH.

**4. Verify the install**

```bash
python -c "import scipy, matplotlib, numpy; print('All good')"
```

**5. (Optional) Use a virtual environment**

Keeps this project's packages isolated from other Python projects on your machine.

```bash
python -m venv venv
# Windows:
venv\Scripts\activate
# macOS/Linux:
source venv/bin/activate

python -m pip install -r requirements.txt
```

## Usage

```bash
python pricer.py         # runs the built-in pricing + IV round-trip test
python plot_greeks.py    # generates greeks_plot.png
```

Example:

```python
from pricer import black_scholes, calculate_greeks, implied_volatility

price = black_scholes(S=100, K=105, T=0.5, r=0.05, sigma=0.20, option_type="call")
greeks = calculate_greeks(S=100, K=105, T=0.5, r=0.05, sigma=0.20, option_type="call")
iv = implied_volatility(market_price=price, S=100, K=105, T=0.5, r=0.05, option_type="call")
```

## Background

Black-Scholes assumes the underlying stock's log-returns are normally distributed (geometric Brownian motion) and prices an option as the probability-weighted, time-discounted expected payoff. Volatility (σ) is the one input that isn't directly observable — everything else (S, K, T, r) is known — which is why implied volatility, rather than the option price itself, is the number volatility trading desks actually watch and trade.
